# 학습·데이터생성 전용 의존성 (런타임 requirements.txt 와 분리)
#
# ★ 왜 분리하나 (2026-07-29 사고 기록)
#   run/requirements.txt 는 deid_cartoon.py **런타임** 핀이다(torch 2.13.0+cu130 /
#   onnxruntime-gpu 1.27.0 / tensorrt-cu13 10.16.1.11). 여기에 학습용 패키지를 섞으면
#   pip 이 런타임 핀을 끌어내린다. 실제로 `pip install facenet-pytorch` 한 번에
#   torch 2.13.0+cu130 → 2.2.2+cu121, numpy 2.5.1 → 1.26.4 로 밀려서
#   onnxruntime 이 `ImportError: libcudart.so.13` 로 아예 import 불가가 됐다.
#   (ORT 1.27 은 CUDA13 빌드라 torch(cu130)가 제공하는 .so 를 쓴다 — setup_venv.sh 38·46줄)
#
# ★ 설치 순서 (반드시 이 순서)
#   1) bash run/setup_venv.sh                  # 런타임 핀 먼저 (torch/ORT/TRT)
#   2) pip install -r run/requirements-train.txt
#   3) pip install --no-deps facenet-pytorch   # ★ --no-deps 필수. 아래 설명 참조
#   4) 검증:
#      python3 -c "import torch,onnxruntime as ort; print(torch.__version__); print(ort.get_available_providers())"
#      → torch 2.13.0+cu130 유지 + TensorrtExecutionProvider 존재해야 정상
#
# ★ 절대 설치하지 말 것
#   - nvidia-*-cu12 계열   : 현재 torch 는 cu130. cu12 라이브러리가 섞이면 libcudart 충돌로 ORT 사망.
#                            (facenet-pytorch 를 --no-deps 없이 깔면 이게 딸려온다)
#   - bitsandbytes         : CUDA 의존으로 cu12 를 끌고 온다. 양자화는 GGUF 로 처리하므로 불필요.
#   - opencv-python-headless : opencv-python 5.0.0 과 cv2 심볼 충돌.
# ============================================================================
